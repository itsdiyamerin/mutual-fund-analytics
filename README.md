* Mutual Fund Analytics

A Python-based data analytics project for analyzing Indian Mutual Funds using AMFI and MFAPI datasets.

## Features

- Data ingestion using Pandas
- NAV history analysis
- AMFI code validation
- Live NAV fetching using MFAPI
- Fund categorization and risk analysis

## Technologies Used

- Python
- Pandas
- Git
- GitHub
- MFAPI
